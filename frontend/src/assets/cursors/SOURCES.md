# Green (Aero) website cursors

Selected from the Frutiger Aero Archive's Resources page:
https://frutigeraeroarchive.org/resources

Original set: Green (Aero) by Abbas, published March 25, 2015.
https://www.rw-designer.com/cursor-set/green-aero
The set's page marks it **Release to Public Domain**.

| Local file | Original download | Embedded hotspot |
| --- | --- | --- |
| aero-normal.cur | https://www.rw-designer.com/cursor-download/73284/Normal%20Select.cur | 0, 0 |
| aero-link.cur | https://www.rw-designer.com/cursor-download/73282/Link%20Select.cur | 5, 0 |
| aero-text.cur | https://www.rw-designer.com/cursor-download/73286/Text%20Select.cur | 15, 16 |
| aero-unavailable.cur | https://www.rw-designer.com/cursor-download/73290/Unavailable.cur | 8, 8 (32px frame) |

Original CUR files are preserved unmodified. Browsers use the embedded hotspots.
Custom cursors apply only to fine pointers with hover and without forced colors.
Native default, pointer, text, and not-allowed fallbacks retain the expected roles.
No cursor animation or cursor-following JavaScript is used.
